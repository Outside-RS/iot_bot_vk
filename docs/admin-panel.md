# Веб-панель

Адрес: `https://<PUBLIC_IP>` на рабочей установке или `http://localhost:3000`
при локальном запуске. Вход по паролю из `ADMIN_PASS`.

Панель — это Express-приложение: маршруты в `routes/admin.js`, страницы в
`views/` (шаблоны EJS), стили и скрипты в `public/`.

Навигация: боковое меню на компьютере, кнопка ☰ и выезжающая шторка на телефоне.

---

## Обзор (`/`)

Четыре карточки состояния:

- **Обращения студентов** — сколько всего за всё время.
- **Ботов запущено** — сколько сообществ подключено прямо сейчас. Ноль — бот ни
  к чему не подключён: смотрите «Группы VK» и журнал.
- **Резервная копия** — дата последней копии. Краснеет, если копия старше двух
  суток, не удалась или не ушла на сервер.
- **ИИ-ассистент** — доступны ли GigaChat и Ollama, какие модели выбраны.

Кнопка **«⚙️ Настройки ИИ»** открывает окно, где вводятся:

| Поле | Что вводить |
|---|---|
| Authorization Key | ключ GigaChat из личного кабинета Сбера. Пусто — текущий останется |
| Scope | `GIGACHAT_API_PERS` для физических лиц |
| Модель | GigaChat-2, -Pro или -Max. С какой начинать перебор классов |
| Адрес сервера Ollama | обычно `http://host.docker.internal:11434` из контейнера |
| Модель Ollama | выбирается из тех, что установлены на сервере Ollama |

Там же — расход токенов по классам моделей и кнопка ↻ «сверить с личным
кабинетом Сбера». Сверка делается только по нажатию, сама по себе панель Сбер
не опрашивает.

Если на главной висит красное предупреждение про код `ADMIN-MAIN` — это общий
тестовый код, по которому администратором может стать любой, кто его введёт.
Порядок замены на личные коды описан в инструкции по переносу.

## База знаний (`/faq`)

Главный рабочий раздел: именно отсюда бот берёт готовые ответы.

**Поиск и фильтры.** Поиск идёт по вопросам, ответам и ключевым словам. Рядом —
фильтр по категории. Сортировка: нажатие на заголовок «№», «Категория» или
«Добавлен», повторное нажатие меняет направление. На странице 25 записей.

**Добавить вопрос** (кнопка разворачивает форму):

| Поле | Что вводить |
|---|---|
| Категория | например «Стипендия». Можно выбрать из существующих |
| Вопрос студента | как спрашивают живые люди: «Как получить социальную стипендию?» |
| Ответ бота | текст, который увидит студент. Без разметки, обычным текстом |
| Ключевые слова | фразы через запятую, по которым студенты будут это искать |

Ключевые слова важны: поиск ищет по вопросу и по ним, ответ в поиске не
участвует. Если по формулировке студента запись не находится — добавьте в
ключевые слова эту формулировку.

**Импорт JSON.** Файл — массив объектов:

```json
[
  {
    "category": "Стипендия",
    "question": "Как получить социальную стипендию?",
    "answer": "Нужно подать заявление...",
    "keywords": "социальная стипендия, выплата"
  }
]
```

Записи с тем же вопросом обновляются, без вопроса или ответа — пропускаются.
После импорта показывается, сколько добавлено, обновлено и пропущено.

**Экспорт в файл** перезаписывает `faq_data.json` в папке проекта данными из
базы. **Скачать базу** отдаёт тот же JSON в браузер.

## Администраторы (`/tutors`)

Коды доступа, по которым человек становится администратором в боте.

| Поле | Что вводить |
|---|---|
| Имя администратора | например «Алёна Смирнова». Попадёт в профиль и в сообщения студентам |
| Код | например `ALENA-2026`. Его человек вводит в боте |

Заводите каждому свой код: по имени видно, кто взял вопрос. Кнопка ✏️ меняет
имя, 🗑 удаляет код.

Удаление кода **не отбирает роль** у того, кто уже вошёл по нему: роль хранится
в профиле пользователя. Чтобы отобрать — удалите человека в разделе
«Пользователи», он пройдёт регистрацию заново.

## Группы VK (`/groups`)

Сообщества, в которых работает бот.

| Поле | Что вводить |
|---|---|
| ID сообщества | номер из адреса сообщества, например `234189923` |
| Токен сообщества | ключ доступа сообщества с правами на сообщения |
| Название | можно не заполнять: подставится из ВКонтакте |

Где взять токен: настройки сообщества → «Работа с API» → «Ключи доступа» →
создать ключ с доступом к сообщениям. Там же включить Long Poll API и события
«Входящие сообщения».

В таблице у каждого сообщества: курс (разобранный из названия), обрезанный
токен, состояние. Кнопки: ↻ сверить название и курс с ВКонтакте, ⏸/▶ отключить
или включить, 🗑 удалить.

Кнопка **«↻ Сверить все с VK»** вверху обновляет названия всех сообществ и при
необходимости переводит студентов на следующий курс. Сама эта сверка выполняется
автоматически 1 августа и 1 сентября.

## Пользователи (`/users`)

Все, кто писал боту.

Поиск по имени и номеру ВКонтакте, фильтры по курсу, группе, роли и статусу.
На странице 25 человек.

Действия по каждому:

| Кнопка | Что делает |
|---|---|
| 🔼 | поднять курс в номере группы на единицу |
| 🎓 | отметить выпускником: курс больше не поднимается |
| 🗑 | удалить профиль. Человек сможет зарегистрироваться заново |

Кнопка **«🔼 Перевести всех на следующий курс»** переводит всех, кто попал под
текущий фильтр. Обычно это не нужно: перевод идёт автоматически по названиям
сообществ.

## Рассылка (`/broadcast`)

Сообщение уходит всем выбранным пользователям бота.

| Поле | Что вводить |
|---|---|
| Кому | всем, студентам, администраторам или одной группе |
| Номер группы | появляется при выборе «Одной группе», формат `РИ-240944` |
| От имени сообщества | из какого сообщества придёт сообщение |
| Текст | обычный текст без разметки |

Отправка идёт постепенно, чтобы ВКонтакте не счёл это спамом. Отменить начатую
рассылку нельзя. В журнале видно, скольким доставлено и скольким нет (человек
мог запретить сообщения от сообщества).

---

## Жалобы (`/feedback`)

Отзывы, которые студенты и администраторы оставляют через кнопку
«⚠️ Жалоба / Отзыв» в боте. У каждого — статус: 🟠 Новое, 🔵 В работе,
🟢 Решено. Статус меняется прямо в списке, 🗑 удаляет запись.

---

## Логи (`/logs`)

Журнал в реальном времени, обновляется раз в секунду.

- **Уровень**: всё с подробностями, события и выше, предупреждения, только ошибки.
- **Подсистема**: `BOT`, `TICKET`, `QUEUE`, `SEARCH`, `COURSE`, `SECURITY`,
  `WORKER`, `DB`, `ADMIN`, `FAQ`, `VK`, `APP`.
- **Поиск** по тексту: номер пользователя, номер обращения, фрагмент сообщения.
- **Скачать файл за день** — выбрать дату в списке и нажать кнопку.

Файлы логов хранятся 14 дней (`LOG_RETENTION_DAYS`). В журнале есть тексты
сообщений студентов, поэтому файлы не попадают в репозиторий.

## Все маршруты

Для тех, кто будет дорабатывать панель.

| Метод и путь | Назначение |
|---|---|
| `GET /login`, `POST /login`, `GET /logout` | вход и выход |
| `GET /` | обзор |
| `GET /api/ai-status` | состояние моделей и расход токенов (для окна настроек) |
| `POST /ai-settings` | сохранить настройки ИИ |
| `DELETE /ai-settings/gigachat-key` | удалить ключ GigaChat |
| `POST /api/ai-balance/refresh` | сверить расход с личным кабинетом Сбера |
| `GET /faq` | база знаний: поиск, фильтр, сортировка, страницы |
| `POST /faq/add`, `GET/POST /faq/edit/:id`, `POST /faq/delete/:id` | правка записей |
| `POST /faq/import-json`, `POST /faq/export-json`, `GET /faq/download-json` | обмен с файлом |
| `GET /tutors`, `POST /tutors/add`, `GET/POST /tutors/edit/:code`, `POST /tutors/delete/:code` | коды администраторов |
| `GET /groups`, `POST /groups/add`, `POST /groups/toggle/:id`, `POST /groups/delete/:id` | сообщества |
| `POST /groups/sync/:id`, `POST /groups/sync-all` | сверка названий с ВКонтакте |
| `GET /users`, `POST /users/promote/:vk_id`, `POST /users/graduate/:vk_id`, `POST /users/delete/:vk_id`, `POST /users/promote-all` | пользователи |
| `GET /broadcast`, `POST /broadcast/send` | рассылка |
| `GET /feedback`, `POST /feedback/status/:id`, `POST /feedback/delete/:id` | отзывы |
| `GET /logs`, `GET /api/logs`, `GET /logs/download/:day` | журнал |

Все маршруты, кроме входа, закрыты проверкой сессии. Все изменяющие запросы
требуют CSRF-токен: в формах он лежит в скрытом поле `_csrf`, в запросах из
JavaScript передаётся заголовком `X-CSRF-Token`.
