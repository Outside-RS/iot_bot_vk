## Коротко о системе

Чат-бот ВКонтакте отвечает на вопросы студентов института тремя способами, по
возрастанию стоимости ответа:

1. **База знаний** — готовый ответ, мгновенно.
2. **ИИ-ассистент** — GigaChat, с подсказками из базы знаний. Резерв — локальная Ollama.
3. **Живой администратор** — если ответа нет и у ИИ.

Плюс веб-панель для управления и обслуживания: база знаний, обращения,
сообщества, пользователи, рассылка, журнал.

Стек: Node.js 22, PostgreSQL 15, Express 5, EJS, vk-io, Docker Compose.
